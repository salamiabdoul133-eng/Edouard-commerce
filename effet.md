Je veux que tu appliques les 3 effets définis précédemment à L'ENSEMBLE DU SITE, et pas uniquement à la page d'accueil.

Commence par analyser toute l'architecture du projet afin d'identifier :

* toutes les pages ;
* toutes les routes ;
* toutes les sections de chaque page ;
* tous les composants réutilisés ;
* les boutons et éléments interactifs ;
* les titres et contenus importants ;
* les images et éléments visuels.

Ensuite, applique intelligemment les 3 effets suivants à travers TOUT LE SITE :

1. TEXT MASK REVEAL
   Applique-le aux titres, grands textes et contenus importants lorsque cela apporte un intérêt visuel.

2. MAGNETIC INTERACTION
   Applique-le aux boutons et éléments interactifs pertinents sur les différentes pages.

3. CLIP-PATH / LIQUID REVEAL
   Applique-le aux images, blocs visuels et sections appropriées.

IMPORTANT :
« Tout le site » signifie toutes les pages et toutes les sections pertinentes du projet, pas seulement la homepage.

Cependant, ne force jamais un effet là où il n'a aucun intérêt. Chaque page doit bénéficier des animations de manière cohérente avec son contenu.

Crée une expérience visuelle cohérente :

* mêmes principes d'animation sur tout le site ;
* mêmes durées et courbes d'animation lorsque les éléments sont similaires ;
* variations uniquement lorsqu'elles améliorent réellement le design ;
* aucune page ne doit sembler oubliée ;
* aucune page ne doit être surchargée.

NE FAIS PAS :

* de nouveaux effets en dehors des 3 définis ;
* d'animations aléatoires ;
* de nouvelles bibliothèques inutiles ;
* de modifications fonctionnelles ;
* de contenu fictif.

PERFORMANCE :

* réutilise les animations et composants lorsque possible ;
* évite de dupliquer inutilement le code ;
* privilégie CSS, transform, opacity et clip-path ;
* optimise les animations sur mobile ;
* désactive les interactions magnétiques sur les appareils tactiles ;
* respecte `prefers-reduced-motion`.

PROCESSUS OBLIGATOIRE :

1. Analyse tout le projet.
2. Liste mentalement toutes les pages et sections concernées.
3. Identifie où chaque effet doit être utilisé.
4. Implémente les effets sur toutes les pages pertinentes.
5. Vérifie qu'aucune page n'a été oubliée.
6. Vérifie desktop, tablette et mobile.
7. Vérifie les performances.
8. Vérifie qu'aucune fonctionnalité existante n'est cassée.

Ne t'arrête pas après avoir modifié la page d'accueil. Parcours réellement le projet et applique le système d'animation à l'ensemble du site.
